# Documentation Archive

This directory contains historical repository material retained for context.
Archived documents may explain why a decision was made, but they may not
describe current product behavior, deployment settings, or supported data
coverage.

Active documentation under `docs/README.md` takes precedence. Do not use an
archived document as current deployment or product instructions without first
reconciling it with the active contracts and quality gate.

## Archive groups

- `audits/` - superseded architecture, legacy-project, and gap audits.
- `implementation-phases/` - completed planning and roadmap material.
- `release-history/` - completed demo scripts, checklists, and screenshot plans.
- `superseded/` - old examples that are not the current operational workflow.
