# Property Case Trusted Evidence v1

## Purpose

案件工作台只把可追溯、可辨識的資料當作證據。估價、找房、位置、地勢、貸款、持有成本與稅務參考各自保留來源狀態，不因缺資料而產生低風險、低價或完成結論。

## Trusted transfer

只有官方估價同時符合以下條件，才可在使用者明確確認後轉入案件價格欄位：

- `valuation_status=available`
- `result_origin=official`
- `is_actionable=true`
- 估價總價、單價與區間皆為正數
- 至少三筆官方 PLVR 可比資料

示範資料、無資料、不可用資料、格式不完整資料，以及未經確認的估價，都不可自動帶入案件、貸款或持有成本。

## Case status

- 草稿最低需求是非空白案件名稱，以及地址或既有明確物件識別。
- 比較最低需求是案件名稱、地址／識別與可比較價格資料。
- 地勢未知或不可用不會被呈現為完整或低風險。
- 市場行情與通勤資訊只是參考，不進入案件決策分數。

## Browser storage boundary

既有案件 storage key 維持不變。保存時只保留安全摘要與狀態，不保存原始交易列、估價 comparables、座標、provider payload、內部 URL 或錯誤細節。不可用資料使用 null 或狀態文字，不以 0 代替。

載入案件只透過既有案件事件恢復畫面，不把完整分析結果重新寫入多個分析 session key。

## Comparison and export

比較評分只使用可用維度並重新正規化權重。少於兩個可評分案件時，分數、排名與最佳案件皆為空。

不完整案件可以產生目前摘要，但必須顯示：

> 本案件資料尚未完整，報告僅彙整目前可用資訊。

部分資料摘要與正式案件報告分開。示範或不可轉移估價不可匯出為正式官方案件報告。案件完整度不是投資評分或買賣建議。
