# Full Locale Administrative Labels v2

## Source and artifact

`frontend_next/lib/taiwan-admin-labels.json` is the checked-in, runtime-offline
label artifact for the 390 canonical county/city and township/district values in
`frontend_next/lib/taiwan-admin-areas.json`.

- English administrative names are normalized from the Ministry of the Interior
  Land Surveying and Mapping Center township-boundary fields `COUNTYENG`,
  `TOWNENG`, and `TOWNCODE`.
- The public catalog reference is Government Data Open Platform dataset `7441`,
  township boundary data. The artifact records the source catalog, source
  fields, and retrieval date; it does not call that source during rendering.
- Japanese labels use a reviewed Kanji normalization policy (`臺` to `台`,
  `縣` to `県`, `區` to `区`, and `鄉` to `郷`) while preserving place identity.
- Korean labels are checked-in Hangul display labels derived from the reviewed
  phonetic policy. They are not generated by an LLM or a runtime translation
  provider.

## Runtime and fallback

The locale resolver matches the canonical value to the artifact and keeps the
canonical `value` and stable `id` unchanged. Unknown county, district, road,
building, source, state, or structured-option values are shown as the original
official value. They are not presented as localized coverage and never receive
a hash, arbitrary number, or fabricated suffix.

## Validation and refresh review

Run the semantic validation before reviewing an artifact update:

```text
python -m pytest -q tests/test_full_locale_data_label_consistency.py
```

An artifact update must be reviewed for all 390 values, official code/name
changes, duplicate canonical values, English source fields, Japanese/Korean
derivation metadata, and numeric-placeholder rejection. The source data is
updated offline through an explicit reviewed import; ordinary selector and map
rendering must remain network-free.

## Coverage definition

Coverage means a non-empty, source-classified, semantically usable label for
each supported locale. A generated number, a generic category plus number, an
untranslated Chinese-only English/Korean label, or an English suffix appended
to an untranslated Chinese label does not count as coverage.
