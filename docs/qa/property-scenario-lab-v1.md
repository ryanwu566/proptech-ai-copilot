Nine model tests pass after the arithmetic fix. No remaining critical/important review findings. The review's saved-finance coverage suggestion is included in the final browser tests.

Implementation decisions: costs are user-entered aggregate amounts, with no tax-rate defaults; commute is a time comparison without a monetary conversion; whole-year holding periods and fixed-rate loans have clear bounded validation; original saved finance price and separately frozen scenario baseline remain distinct.
