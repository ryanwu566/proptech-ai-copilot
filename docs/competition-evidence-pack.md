# Competition Evidence Pack

## Demonstrable evidence

- TaxOracle uses deterministic TX001-TX009 compatibility screening.
- Holding Cost uses the existing deterministic current-input service.
- Results expose rule/source metadata, used inputs, missing facts, and a
  preliminary limitation.
- The three-minute demo is editable, resettable, and has an explicit offline
  rehearsal mode.

## Validation record

The release records implementation and browser-test status in the canonical
runtime matrix. Customer interviews, paid pilots, customer logos, accuracy
percentages, time-saving percentages, revenue, and professional endorsements
are **not yet validated** and must not be presented as claims.

## Source and review boundary

Official source metadata is displayed when the existing service provides it.
Unavailable, stale, missing, or incomplete data remains unresolved. Tax
professionals, banks, appraisers, lawyers, land agents, and government agencies
remain responsible for final decisions.

## Reproduction checklist

1. Open the homepage and choose the three-minute TaxOracle demo.
2. Run the illustrative example.
3. Change property price and at least two qualification facts.
4. Recalculate and inspect the changed output and input trace.
5. Open Evidence, Privacy, Terms, and browser print.

The example contains no real customer data and is not evidence of market
validation.
